# Instance Segmentation

> Bài toán xác định từng object riêng biệt ở cấp độ pixel.

## Vấn đề cần giải quyết
Các object cùng class cần được phân biệt thành từng instance.

## Input
Một image.

## Output
Mask cho từng object/instance.

## Ví dụ
Person 1 → Mask; Person 2 → Mask

## Câu hỏi cốt lõi
> Object nào đang chiếm những pixel nào và từng object là instance nào?
