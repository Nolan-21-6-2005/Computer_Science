# Action Recognition

> Bài toán xác định hành động đang diễn ra trong một đoạn video.

## Vấn đề cần giải quyết
Hệ thống không chỉ cần nhận biết object mà còn phải hiểu hành động của chúng theo thời gian.

## Input
Video / chuỗi frames.

## Output
Action class.

## Ví dụ
Video → Walking / Running / Falling
