# OCR

> Bài toán chuyển nội dung chữ xuất hiện trong hình ảnh thành dữ liệu text.

## Vấn đề cần giải quyết
Thông tin trong tài liệu hoặc hình ảnh tồn tại dưới dạng pixel nhưng hệ thống cần xử lý nó như text.

## Input
Image chứa text.

## Output
Text.

## Ví dụ
Image → "Nguyen Van A"

## Câu hỏi cốt lõi
> Trong hình ảnh đang chứa nội dung văn bản gì?
