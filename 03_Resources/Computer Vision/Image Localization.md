# Image Localization

> Bài toán xác định vị trí của một object trong ảnh.

## Vấn đề cần giải quyết
Hệ thống cần biết vị trí của object thay vì chỉ biết class.

## Input
Một image.

## Output
Class + Bounding Box.

## Ví dụ
Ảnh → Object + Bounding Box

## Câu hỏi cốt lõi
> Object cần tìm nằm ở đâu trong ảnh?
