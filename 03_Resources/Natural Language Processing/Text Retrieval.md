# Text Retrieval

> Bài toán tìm các văn bản phù hợp với một query từ một tập dữ liệu.

## Vấn đề cần giải quyết
Người dùng cần nhanh chóng tìm được tài liệu liên quan trong kho dữ liệu lớn.

## Input
Query + corpus.

## Output
Ranked documents.

## Ví dụ
Query → top-k documents
