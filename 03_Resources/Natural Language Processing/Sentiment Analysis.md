# Sentiment Analysis

> Bài toán xác định cảm xúc hoặc thái độ được thể hiện trong văn bản.

## Vấn đề cần giải quyết
Hệ thống cần xác định người viết đang thể hiện thái độ/cảm xúc gì.

## Input
Text.

## Output
Sentiment label/score.

## Ví dụ
"This product is amazing!" → Positive

## Câu hỏi cốt lõi
> Văn bản đang thể hiện cảm xúc hoặc thái độ như thế nào?
