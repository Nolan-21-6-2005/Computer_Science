# Language Modeling

> Bài toán mô hình hóa xác suất hoặc khả năng xuất hiện của chuỗi token.

## Vấn đề cần giải quyết
Hệ thống cần học quy luật của ngôn ngữ để dự đoán hoặc sinh token.

## Input
Sequence of tokens.

## Output
Probability/distribution over tokens.

## Ví dụ
P(next token | context)

## Câu hỏi cốt lõi
> Với context hiện tại, token nào có khả năng xuất hiện tiếp theo?
