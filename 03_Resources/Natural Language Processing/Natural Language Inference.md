# Natural Language Inference

> Bài toán xác định quan hệ logic/ngữ nghĩa giữa một premise và hypothesis.

## Vấn đề cần giải quyết
Hệ thống cần biết hypothesis có được suy ra, mâu thuẫn hoặc không xác định từ premise hay không.

## Input
Premise + hypothesis.

## Output
Entailment / Contradiction / Neutral.

## Ví dụ
Premise + Hypothesis → label

## Câu hỏi cốt lõi
> Hypothesis có được hỗ trợ bởi premise không?
