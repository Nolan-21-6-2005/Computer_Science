# Text Correction

> Bài toán phát hiện và sửa lỗi trong văn bản.

## Vấn đề cần giải quyết
Hệ thống cần biến văn bản có lỗi thành văn bản đúng hoặc phù hợp hơn.

## Input
Text.

## Output
Corrected text.

## Ví dụ
"I has a book" → "I have a book"

## Câu hỏi cốt lõi
> Văn bản đang sai ở đâu và phiên bản đúng là gì?
