
## Model
- **Số lượng tham số (Parameters)** → Quy mô của mô hình và lượng trọng số cần học/lưu trữ.
- **Kích thước embedding (Embedding Dimension)** → Số chiều dùng để biểu diễn mỗi token.
- **Context Window** → Số lượng token tối đa mô hình có thể xử lý trong một lần.
- **Vocabulary Size** → Số lượng token khác nhau mà tokenizer/mô hình có thể biểu diễn.

## Input
- **Số lượng token của văn bản (Token Count)** → Lượng token mà văn bản được chuyển thành sau khi tokenize.
- **Độ dài văn bản (Text Length)** → Kích thước văn bản đầu vào, thường được đo bằng ký tự, từ hoặc token.
- **Token-to-Word Ratio** → Mức độ một văn bản được phân tách thành nhiều token so với số lượng từ.

## Computational
- **Inference Time** → Thời gian mô hình xử lý một input và tạo output.
- **Memory Usage** → Lượng bộ nhớ cần thiết để lưu mô hình và thực hiện tính toán.
- **Computational Cost** → Lượng tài nguyên tính toán cần thiết để huấn luyện hoặc suy luận.
