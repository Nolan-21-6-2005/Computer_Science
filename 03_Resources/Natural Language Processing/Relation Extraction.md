# Relation Extraction

> Bài toán xác định quan hệ giữa các thực thể trong văn bản.

## Vấn đề cần giải quyết
Hệ thống cần biết các entity liên hệ với nhau như thế nào.

## Input
Text + entities.

## Output
Relations.

## Ví dụ
Person → works_at → Organization

## Câu hỏi cốt lõi
> Các thực thể trong văn bản có quan hệ gì với nhau?
