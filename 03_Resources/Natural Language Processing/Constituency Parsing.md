# Constituency Parsing

> Bài toán phân tích câu thành các cụm ngữ pháp có cấu trúc phân cấp.

## Vấn đề cần giải quyết
Hệ thống cần hiểu cách các từ kết hợp thành phrase và cấu trúc câu.

## Input
Sentence.

## Output
Parse tree.

## Ví dụ
S → NP + VP

## Câu hỏi cốt lõi
> Câu được cấu thành từ những cụm ngữ pháp nào?
