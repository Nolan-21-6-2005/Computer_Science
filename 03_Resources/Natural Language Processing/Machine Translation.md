# Machine Translation

> Bài toán chuyển nội dung từ một ngôn ngữ sang ngôn ngữ khác trong khi cố gắng giữ nguyên ý nghĩa.

## Vấn đề cần giải quyết
Người dùng cần hiểu hoặc tạo nội dung bằng một ngôn ngữ khác mà không cần dịch thủ công.

## Input
Source text.

## Output
Target text.

## Ví dụ
English → Vietnamese

## Câu hỏi cốt lõi
> Làm thế nào để chuyển nội dung sang ngôn ngữ khác mà vẫn giữ được ý nghĩa?
