# Dependency Parsing

> Bài toán xác định quan hệ phụ thuộc ngữ pháp giữa các từ trong câu.

## Vấn đề cần giải quyết
Hệ thống cần mô hình hóa cấu trúc quan hệ giữa các từ.

## Input
Sentence.

## Output
Dependency tree/relations.

## Ví dụ
subject, object, modifier...

## Câu hỏi cốt lõi
> Các từ trong câu phụ thuộc và liên kết với nhau như thế nào?
