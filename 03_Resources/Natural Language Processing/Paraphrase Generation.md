# Paraphrase Generation

> Bài toán tạo một cách diễn đạt khác nhưng giữ nguyên hoặc gần nguyên ý nghĩa của văn bản.

## Vấn đề cần giải quyết
Hệ thống cần thay đổi cách diễn đạt mà không làm mất nội dung.

## Input
Text.

## Output
Paraphrased text.

## Ví dụ
"How are you?" → cách diễn đạt tương đương

## Câu hỏi cốt lõi
> Làm thế nào diễn đạt lại nội dung mà vẫn giữ ý nghĩa?
