# Conversational AI

> Bài toán xây dựng hệ thống có khả năng tương tác với con người bằng ngôn ngữ tự nhiên.

## Vấn đề cần giải quyết
Người dùng cần giao tiếp với hệ thống theo cách tự nhiên thay vì thông qua giao diện cứng.

## Input
User utterance + context.

## Output
Response/action.

## Ví dụ
Chat assistant

## Câu hỏi cốt lõi
> Hệ thống cần hiểu và phản hồi người dùng như thế nào?
