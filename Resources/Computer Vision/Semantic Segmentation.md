# Semantic Segmentation

> Bài toán gán một class cho từng pixel trong ảnh.

## Vấn đề cần giải quyết
Bounding Box không xác định chính xác hình dạng object.

## Input
Một image.

## Output
Một class label cho mỗi pixel.

## Ví dụ
Pixel → Road / Car / Person

## Câu hỏi cốt lõi
> Mỗi pixel trong ảnh thuộc về class nào?
