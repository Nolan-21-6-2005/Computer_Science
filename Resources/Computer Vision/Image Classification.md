# Image Classification

> Bài toán xác định class của toàn bộ một ảnh.

## Vấn đề cần giải quyết
Hệ thống cần biết ảnh đang chứa hoặc biểu diễn đối tượng/concept nào.

## Input
Một image.

## Output
Một class hoặc xác suất của các class.

## Ví dụ
Ảnh → Cat
