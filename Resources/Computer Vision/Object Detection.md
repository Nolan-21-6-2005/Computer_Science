# Object Detection

> Bài toán xác định object nào xuất hiện và vị trí của chúng trong ảnh.

## Vấn đề cần giải quyết
Classification chỉ cho biết ảnh chứa gì, nhưng hệ thống còn cần biết object nằm ở đâu.

## Input
Một image.

## Output
Class + Bounding Box + Confidence.

## Ví dụ
Person → [x1, y1, x2, y2]

## Câu hỏi cốt lõi
> Có object nào và chúng nằm ở đâu?
