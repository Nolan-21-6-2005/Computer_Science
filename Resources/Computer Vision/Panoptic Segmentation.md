# Panoptic Segmentation

> Bài toán phân vùng toàn bộ ảnh đồng thời phân biệt từng instance của các object.

## Vấn đề cần giải quyết
Hệ thống cần hiểu toàn bộ cảnh, bao gồm cả object và background.

## Input
Một image.

## Output
Mỗi pixel có semantic class và instance ID nếu thuộc object.

## Ví dụ
Pixel → Class + Instance

## Câu hỏi cốt lõi
> Toàn bộ các pixel trong cảnh thuộc về cái gì và thuộc instance nào?
