# Object Tracking

> Bài toán theo dõi cùng một object qua nhiều frame của video.

## Vấn đề cần giải quyết
Detection chỉ xác định object trong từng frame, nhưng video cần duy trì identity của object theo thời gian.

## Input
Chuỗi video frames.

## Output
Object location + Identity theo thời gian.

## Ví dụ
Person ID 1 → frame 1, 2, 3...

## Câu hỏi cốt lõi
> Object này đang di chuyển như thế nào qua các frame?
