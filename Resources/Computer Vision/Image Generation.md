# Image Generation

> Bài toán tạo ra hình ảnh mới dựa trên dữ liệu hoặc điều kiện đầu vào.

## Vấn đề cần giải quyết
Hệ thống cần tạo ra nội dung hình ảnh thay vì chỉ phân tích hình ảnh có sẵn.

## Input
Text, image, noise hoặc condition.

## Output
Image.

## Ví dụ
Prompt → Generated Image

## Câu hỏi cốt lõi
> Làm thế nào để tạo ra một hình ảnh phù hợp với điều kiện đầu vào?
