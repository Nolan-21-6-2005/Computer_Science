# Dialogue Systems

> Bài toán xây dựng hệ thống có khả năng duy trì và điều khiển cuộc hội thoại theo lượt.

## Vấn đề cần giải quyết
Hệ thống cần xử lý nhiều lượt tương tác thay vì chỉ trả lời một input độc lập.

## Input
Conversation history + user input.

## Output
System response/action.

## Ví dụ
User → System → User → System

## Câu hỏi cốt lõi
> Hệ thống cần phản hồi thế nào dựa trên lịch sử hội thoại?
