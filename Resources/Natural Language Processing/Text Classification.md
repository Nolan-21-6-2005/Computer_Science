# Text Classification

> Bài toán phân loại một đoạn văn bản vào một hoặc nhiều class.

## Vấn đề cần giải quyết
Hệ thống cần xác định chủ đề, ý định hoặc loại của text.

## Input
Text.

## Output
Class(es).

## Ví dụ
"How do I reset my password?" → Password Reset

## Câu hỏi cốt lõi
> Văn bản này thuộc nhóm nào?
